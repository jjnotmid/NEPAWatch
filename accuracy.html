How we measure accuracy
The system is fully automated — no human curates these numbers
1. AI files a report
When NEPAWatch AI predicts an outage above 58% probability, it files a report tagged "NEPAWatch AI" and logs the prediction with timestamp and probability.
2. Humans respond
Other users in the same area confirm or mark it wrong. 2+ confirms = correct. 2+ wrong-votes = wrong. These votes are crowd-sourced and unweighted.
3. Outcome recorded
3 hours after each prediction, a server-side function checks the human votes and writes correct/wrong/unresolved. This runs hourly via pg_cron.
4. Model corrects itself
Wrong predictions reduce the area's accuracy weight (×0.82). Correct ones increase it (×1.06). These weights are applied to future predictions globally.
