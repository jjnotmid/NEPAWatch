Quick Start

Two lines to get data

Pass your API key in the X-API-Key header. All responses are JSON.

cURL
JavaScript
# Get latest 10 outages in Lagos
curl "https://djurokbkkqrmpafcxlez.supabase.co/functions/v1/nepawatch-api?state=Lagos&type=out&limit=10" \
  -H "X-API-Key: YOUR_API_KEY"
const res = await fetch(
  'https://djurokbkkqrmpafcxlez.supabase.co/functions/v1/nepawatch-api?state=Lagos&type=out&limit=10',
  { headers: { 'X-API-Key': 'YOUR_API_KEY' } }
);
const { data, meta } = await res.json();
console.log(data); // Array of outage reports
Endpoints

Available endpoints

The API currently exposes one endpoint for reading outage reports. More endpoints are planned.

GET /nepawatch-api List outage reports

Query Parameters

Parameter Type Description
state string Filter by state name (partial match). E.g. Lagos
lga string Filter by Local Government Area (partial match)
area string Filter by area/neighbourhood name (partial match)
type string out for outages, bck for restorations
since ISO date Return reports after this timestamp. E.g. 2025-01-01T00:00:00Z
limit integer Results per page — max 100, default 50
offset integer Pagination offset, default 0
